GX27 — Update v40 (28 Okt 2026)

Cara pasang:
1. Upload SEMUA isi folder ini ke repo GitHub (timpa file lama). Vercel deploy otomatis (1–2 menit).
2. Tidak perlu jalankan SQL. (supabase/schema.sql sekarang sama dengan schema.sql di folder utama.)
3. Buka website, tekan Cmd+Shift+R (Mac) / Ctrl+Shift+R (Windows) sekali.

Yang baru:
1. Tasks → Need per Station: klik "Need: … →" di task, atau tombol "Need station" di detail task,
   langsung ke station yang tepat (di-highlight). Task biasa yang namanya cocok dengan station
   (mis. "GX Face Art - Face Painting") otomatis ditautkan; bisa dipilih manual di detail task.
   "+ Checklist Need" sekarang langsung membuka station yang baru dibuat.
2. Master Timeline: default hanya GX Connect, GX Got Talent, Mobile Legends, HYROX (+ Event Day).
   Tombol "⚙ Program" untuk centang workstream lain.
3. Finance — Sumber Budget per item & sub item (sub item di Budget Pool juga bisa):
   - Budget RAB item ini
   - Budget RAB + tambahan dari buffer (kalau over budget)
   - Seluruhnya dari buffer
   Sumbernya bisa "Buffer umum" atau sisa item tertentu yang hemat.
   Panel "Ringkasan Budget & Buffer": Hemat − Over budget − Dipakai = Sisa buffer, daftar pemakaian
   buffer, dan daftar over budget dengan tombol "Tutup pakai buffer".
4. Emergency Fund (Budget Pool) → tombol "Sections": tambah/ubah/hapus section dan pilih program
   terkaitnya (mis. "EF Mobile Legends" → Mobile Legends). Filter kategori Mobile Legends ikut
   menampilkan item section itu.
   Tanda "Reimbursement" di form item (+ reimburse ke siapa). Item tetap di section-nya dan juga
   muncul di daftar Reimbursement (tombol "Reimbursement" di toolbar Finance).
5. Presentation jadi deck 7 slide (Cover, Highlights, Program Utama, Progress Task, Budget,
   Buffer, Deadline), tiap slide ada kotak Highlight. Pindah slide pakai tombol ← → atau keyboard.
   Semua nominal dalam Rupiah lengkap (Rp 204.280.139).
